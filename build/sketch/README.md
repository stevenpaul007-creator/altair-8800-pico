# Altair2040 - Altair 8800 emulator on Raspberry Pi Pico (RP2040)

An RP2040 (Raspberry Pi Pico) port of the Arduino Altair101a project: an Intel
8080 CPU emulator with a virtual front panel, originally by tigerfarm
(https://github.com/tigerfarm/arduino/tree/master/instructables/Altair101a).

The 8080 emulator core is kept almost unchanged. The front panel (LEDs and
switches), which was driven by 74HC595 shift registers on the Mega/Due, is now
driven by FOUR PCA9555 I2C port-expanders on the Pico. The console and the 8080
serial I/O go over USB CDC; an optional auxiliary UART is exposed on Serial1.

NOTE: No SD/TF card, MP3 player, or real-time-clock support is built in. Those
modules are present only as empty stubs (their menu commands exist but do
nothing). See "Limitations" below.

## 1. Hardware

- Raspberry Pi Pico (RP2040).
- 4 x PCA9555 (or compatible; PCF8575 is NOT a drop-in replacement).
  Addresses 0x20, 0x21, 0x22, 0x23 (set by wiring A0/A1/A2).
- Front-panel LEDs and switches wired to the PCA9555 ports (see section 3).
- USB cable for power, UF2 programming, and the CDC console.

### 1.1 Wiring / pull-up notes

- I2C bus (SDA/GP6, SCL/GP7): add 4.7 kOhm pull-ups to 3V3 on both lines. The
  RP2040 internal pull-ups are too weak for reliable I2C.
- Button / switch inputs on the PCA9555: the PCA9555 has NO internal pull-ups.
  Every button pin needs an external 10 kOhm pull-up to 3V3; the switch shorts
  the pin to GND when closed (active LOW).
- LED outputs: active LOW (a LOW output lights the LED). Use a suitable series
  resistor (e.g. 330 ohm) from the pin to the LED cathode, anode to 3V3.

## 2. GPIO assignment (RP2040 Pico)

  Signal                         GPIO                Notes
  USB CDC console + 8080 serial  USB (no GPIO)       'Serial' in the sketch.
  Auxiliary UART (Serial1,UART0)  GP0=TX, GP1=RX      Optional external terminal; 115200 baud default.
  Panel I2C (Wire1)              GP6=SDA, GP7=SCL    PCA9555 @ 0x20-0x23, 400 kHz. Pins configurable in Panel9555.h (PANEL_SDA_PIN / PANEL_SCL_PIN).
  Onboard LED                   GP25                 Not used by the sketch.
  GP5                            free                Was legacy 74HC595 data pin; its driver is disabled on RP2040.

All front-panel LEDs and switches sit behind the PCA9555s - they use NO
additional RP2040 GPIO. The rest of the GPIOs are free for your own use.

The legacy 74HC595 shift-register LED driver (lightsStatusAddressData) is
intentionally a no-op on RP2040: enabling it would drive GP6/GP7 and collide
with the I2C panel. Do not re-enable it.

## 3. PCA9555 front-panel mapping

  Chip   Address  io0 (outputs, LEDs, active LOW)            io1 (inputs, active LOW)
  0x20   0        D0-D7 data LEDs                          Data/address switches A0-A7 (reversed: io1_k -> bit 7-k)
  0x21   1        A0-A7 address LEDs                       Command buttons: EXAMINE, EXAMINE NEXT, DEPOSIT, DEPOSIT NEXT, RESET, CLR, PROTECT, UNPROTECT
  0x22   2        Status LEDs: INT,WO,STACK,HLTA,OUT,M1,INP,MEMR   Address switches A8-A15 (reversed: io1_k -> bit 15-k)
  0x23   3        A8-A15 address LEDs                      io1_0-3: INTE,PROT,WAIT,HLDA status LEDs; io1_4-7: STOP,RUN,SINGLE STEP,AUX buttons

- Data/address switches (0x20 io1, 0x22 io1) feed fpAddressToggleWord, bit-
  reversed as noted. The 16-bit word is the address used by EXAMINE; its low 8
  bits are the data byte written by DEPOSIT (classic Altair layout). Switches
  REFLECT their physical position (a closed switch = bit set).
- Command buttons send the equivalent console key: STOP/SINGLE STEP -> 's',
  RUN -> 'r', EXAMINE -> 'x', EXAMINE NEXT -> 'X', DEPOSIT -> 'p',
  DEPOSIT NEXT -> 'P', RESET -> 'R', CLR -> 'C'. PROTECT/UNPROTECT toggle the
  status_prot flag (shown on the PROT LED). AUX is reserved (no function yet).
- Everything is defined in panel_config.h - the only file you edit to rewire
  the panel.

## 4. Building and flashing

### 4.1 Prerequisites

- arduino-cli with the earlephilhower RP2040 core:
    arduino-cli core install rp2040:rp2040
- If GitHub downloads stall, set HTTPS_PROXY / HTTP_PROXY.

### 4.2 Build

Use the provided script (output UF2 goes to build/):
    cd Altair2040
    ./build.sh

Or directly:
    arduino-cli compile --fqbn rp2040:rp2040:rpipico       --build-property build.extra_flags='-Wno-error=deprecated-declarations -Wno-deprecated-declarations'       Altair2040.ino

The extra_flags silences the RP2040 core's -Werror on legacy Bxxxx binary
literals in the original code.

### 4.3 Flash

Hold BOOTSEL on the Pico, plug in USB, copy build/Altair2040.ino.uf2 to the
RPI-RP2 drive. After reboot, open a serial terminal (115200, 8N1) on the USB
CDC port.

## 5. Serial console commands

Typed into the USB CDC console (also generated by the front-panel buttons):

    s   STOP (in RUN) / SINGLE STEP (in WAIT)
    r   RUN
    x   EXAMINE - set PC to the switch word, show data
    X   EXAMINE NEXT - PC+1, show data
    p   DEPOSIT - write data byte to memory at PC
    P   DEPOSIT NEXT - PC+1 then deposit
    R   RESET - PC = 0
    C   CLR - clear memory and registers
    0-9, a-f   toggle a switch bit (console only)
    l   load a sample program
    i   info - registers AND a memory dump (hex + ASCII) around PC and SP
    j   settings info
    u/U log messages off/on
    v/V VT100 virtual front panel on/off
    t/T terminal escape codes on/off
    h   help
    L   load Intel hex from serial
    o/O LED output enable/disable (legacy; no effect on PCA9555 panel)
    w/W USB serial output on/off
    y/Y, B, D   auxiliary Serial1 (UART) controls - optional

The 'i' info line prints a data byte as 2-3-3 bit groups + hex, e.g.
"00 111 010  (3A)". For x/X/p/P the data is shown on the SAME line as the
address, right-aligned.

SD-card / MP3 / clock commands (F, m, M, n, J, Q, q, ...) are menu
placeholders only - they do nothing (see Limitations).

## 6. Limitations / not implemented

- No TF/SD card support. The SD read/write functions are empty stubs;
  setupSdCard() always returns false. Load/save is via the serial console or
  samples only.
- No MP3 player, no real-time clock (also stubs).
- The PCA9555 must be exactly PCA9555 (PCF8575 is not a drop-in replacement).
- Verified by compiling and by the no-panel code path; the physical I2C/LED/
  switch behaviour should be checked on real hardware.
